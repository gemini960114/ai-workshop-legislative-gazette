# 公報文件查詢整理（行政人員示範）

用自然語言請 AI AGENT 查詢立法院公報、整理成文件，並輸出 Word 或 PDF。不需要寫程式。

## 資料夾

```
公報資料/        立法院教育及文化委員會公報 6 場（與國科會、國研院、國網中心相關）
  00_檔案清單.md  每場的主題、主席、質詢委員、重點
整理結果/        Claude 產出的文件放這裡（立委發言／國網議題／預測分析）
工具/轉檔.ps1    把整理好的文件轉成 Word 和 PDF
```

| 日期 | 會議 | 主題 |
| --- | --- | --- |
| 4/8 | 第5次 | 國科會業務報告 |
| 4/29 | 第8次 | AI 主權專題報告（中研院、國科會、數發部；國網中心列席） |
| 5/6 | 第9次 | 故宮業務報告、國科會預算詢答 |

## 事前準備

- 下載並開啟本資料夾
- 轉 Word 需要 pandoc；轉 PDF 需要 Microsoft Word（Windows）

## 示範流程

每一步都直接用中文問，一次問一件事，再接著追問就好。下面是建議問法。

> 💡 看到答案後，可以再問：「出處在哪一份、第幾行？」、「這是公報寫的，還是你推測的？」

### 1. 認識資料

- 「這個資料夾裡有什麼？」
- 「哪一場最常提到國網中心？」
- 「4 月 29 日那場，國網中心誰有出席？」

### 2. 查一位委員，存成 Word

- 「葛如鈞委員問了什麼？」
- 「只要跟 AI、算力有關的。」
- 「做成表格。」
- 「存到 整理結果/立委發言，轉成 Word。」

預期：列出算力 MW 與 GW 的落差、AI Token 補助、TAIDE 答錯的示範、算力預購等，每點附檔名和行號；資料夾裡會出現一份 .md 和一份 .docx。

### 3. 再多查幾位

- 「陳培瑜委員也幫我整理一份，一樣存成 Word。」
- 「比較葛如鈞和陳培瑜關心的重點有什麼不同。」

### 4. 國網中心議題，存成 Word

- 「哪些委員問到國網中心？問了什麼？」
- 「依主題分類，做成表格。」
- 「立法院對國研院的預算做了哪些決議？」（答案在 6/24 那份的議事錄）
- 「國科會答應過委員哪些事？」
- 「把以上整理成一份文件，存到 整理結果/國網議題，轉成 Word。」

### 5. 上網查詢，做預測報告

- 「上網查葛如鈞最近跟 AI 有關的新聞。」
- 「下次開會，委員可能會問國網中心什麼？要準備哪些資料？」
- 「整理成報告，存到 整理結果/預測分析，轉成 Word 和 PDF。」

預期：報告中把【公報記載】【網路資訊】【分析推測】分開標示，網路資訊附來源與日期。

### 6. 檢查與輸出

- 「整理結果裡有哪些文件？」
- 「把還沒轉的都轉成 Word。」
- 打開 整理結果 資料夾，用 Word 開啟檔案確認內容。

## 注意

- 資料只有 6 場會議，不是整個會期。
- 部分預算提案、條文對照表在原始公報中是掃描圖片，這裡沒有文字。
- 網路搜尋結果和預測僅供參考，正式使用前請人工核對。
